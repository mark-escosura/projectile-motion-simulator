# 🚀 Projectile Motion Simulator

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Made with JavaScript](https://img.shields.io/badge/Made%20with-JavaScript-yellow.svg)](https://www.javascript.com)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](http://makeapullrequest.com)

A physics-based web application that simulates projectile motion in real-time, allowing users to visualize and understand the fundamental principles of projectile motion. Perfect for students, teachers, and physics enthusiasts!

## ✨ Features

- 🎯 Interactive simulation of projectile motion
- ⚙️ Adjustable parameters:
  - Initial velocity (m/s)
  - Launch angle (degrees)
  - Initial height (m)
- 📊 Real-time visualization with HTML5 Canvas
- 📈 Flight statistics display:
  - Maximum height
  - Flight time
  - Distance traveled
- 📱 Responsive design for all devices
- ♿ Accessible interface following WCAG guidelines

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- HTML5 Canvas for visualization
- Modern CSS Grid and Flexbox for layout

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/mark-escosura/projectile-motion-simulator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd projectile-motion-simulator
   ```

3. Open `index.html` in your web browser to run the simulator.

## 📖 Usage

1. Set the initial parameters:

   - Initial velocity (m/s): The speed at which the projectile is launched
   - Launch angle (degrees): The angle between the ground and the launch direction (0-90°)
   - Initial height (m): The height from which the projectile is launched

2. Click the "Start Simulation" button to begin the simulation.

3. Observe the projectile's trajectory and flight statistics in real-time.

## 🎯 Physics Concepts Demonstrated

- Projectile motion equations
- Parabolic trajectories
- Conservation of energy
- Vector decomposition
- Time of flight calculations
- Maximum height calculations
- Range calculations
